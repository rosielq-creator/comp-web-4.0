# Hero Components

## Official Logo

Uses the canonical Greentomato SVG as a CSS mask. The logo color is controlled
with the official green token and must not be redrawn as text.

## Header

Transparent over the hero with no boxed template chrome. Links use compact,
medium-weight sans-serif type. The project action remains the strongest control.

## Orbit Mark

A lightweight original line icon that signals global digital talent. It is
decorative and hidden from assistive technology.

## Hero Wordmark

The canonical logo is enlarged, bottom-cropped, and treated as architecture
rather than a conventional footer-sized brand mark.

# GTAI 本次改版总方案

日期：2026-07-23  
状态：设计方案确认稿；未修改网站代码  
范围：全站公共框架、Home、Work、视频播放器与动效治理

## 1. 改版目标

本次不是给现有页面继续叠加装饰，而是重新建立清晰的视觉层级：

1. Home 第一眼说清 GTAI 是 AI talent agency；
2. 五位艺人获得完全平等的曝光与交互成本；
3. Work 像创意公司的精选作品集，而不是视频素材库；
4. 全站只保留一个真正有记忆点的招牌动效；
5. 桌面、手机分别排版，而不是把桌面场景缩小塞进手机。

## 2. 总体设计方向

方向名：**Editorial Stage / 编辑部舞台**

- 视觉关键词：编辑感、克制、未来、玻璃质感、精准网格、大留白。
- 颜色：保留 GTAI 米白、近黑、品牌绿；品牌绿只用于关键状态与 CTA。
- 字体：最多两套字体，一套展示字体、一套正文/数据字体。
- 网格：桌面 12 栏，内容最大宽度约 1280px；使用统一外边距与 8px 间距体系。
- 动效：页面揭示、Roster 交互、Hero 果冻视觉三类；同一视区最多一个持续环境动效。
- 页面恢复自然纵向滚动，不再把所有内容锁进一个 `100svh` 场景。

## 3. 全站公共框架

### Header

- 桌面保持 GTAI Logo、主要页面入口、语言和声音控制。
- 精简顶栏信息密度，当前页只用细线或颜色标记，不增加徽章。
- 手机端改为 Logo + 菜单按钮；完整导航进入可访问的抽屉/弹层。
- 所有点击区域至少 44 × 44px，保留清晰的键盘焦点。

### 页面转场

- 使用 300–450ms 的淡入与轻微位移，不使用 bounce。
- 不用复杂 shader 作为每次换页的必经步骤。
- `prefers-reduced-motion` 下只保留快速淡入。

### 代码治理

- 不在 `styles.css` 底部继续叠加覆盖规则。
- 实施时重建独立的 Home、Work 和 Video Controls 样式模块。
- 清除旧 Home 的排名、轨道、物理字块等废弃 DOM、CSS 和动画循环。
- 页面离开、标签页隐藏或元素离开视区时暂停 RAF、视频预览和 WebGL。

## 4. Home 最终方案

Home 改为三段式短页面，每一屏只完成一个任务。

### Section 1 — Hero / 品牌定位

桌面布局：

```text
┌─────────────────────────────────────────────────────────┐
│ GTAI                                      NAV / TOOLS    │
│                                                         │
│ AI TALENT AGENCY                 [中央 3D GTAI 玻璃标志] │
│ 一句明确的品牌主张                                      │
│ 一句简短说明                                            │
│ [Explore Artists]  [Selected Work]                      │
└─────────────────────────────────────────────────────────┘
```

- 左侧是品牌定位、说明和两条路径。
- 右侧/中央是唯一视觉中心：3D GTAI 玻璃标志或抽象品牌徽章。
- 首屏不同时展示五位艺人，不显示 Services 长文，不显示排名。
- 主 CTA 进入艺人区；次 CTA 进入 Work。
- 文案最终另行确认，本轮只确定信息层级。

### Hero 招牌动效

借鉴 Haoqi `Hello` 的手感，但不复制它的字样或整套视觉：

1. 静态 GLTF 品牌模型；
2. 玻璃折射、轻微色散和鼠标追随高光；
3. 低分辨率 GPU 流体速度场偏移模型周围的画面 UV；
4. 鼠标移动时出现局部拖拽、回流和惯性；
5. 停止约 600ms 后自然恢复并停止计算；
6. 加非常轻的相机视差，不做模型 bounce。

推荐起始参数：

| 参数 | 建议 |
| --- | --- |
| 位移强度 | `0.18–0.24` |
| 影响半径 | `1.0–1.3` |
| 模拟分辨率 | 桌面 `160`，低性能设备 `96–128` |
| 压力迭代 | `4` |
| DPR 上限 | `1.5` |
| 空闲停止 | 约 `600ms` |

明确排除：

- 掉落贴纸；
- 物理散件；
- 鼠标尾巴；
- 粒子雨；
- 多个 3D 物体同时漂浮；
- 全屏持续扭曲；
- 与旧轨道/水晶/字块动画共存。

移动端显示静态或轻微漂浮的玻璃标志，不运行完整指针流体；低性能、WebGL 失败和 reduced-motion 模式均保留完整 HTML 文案与 CTA。

### Section 2 — Equal Roster / 五位艺人

- 五位艺人面积、字号、入口成本完全一致。
- 移除 `#01–#05` 排名含义和 `MOST LOVED`。
- 桌面推荐使用“名字索引 + 一个共享肖像舞台”：
  - Hover、键盘 focus 或点击名字时，右侧共享舞台切换肖像；
  - 切换采用 220–300ms 淡入淡出，不做大幅缩放；
  - 细线在 140–180ms 内展开作为反馈。
- 若需要编号，只作为中性导航序号 `01 / 05`，不代表受欢迎程度。
- 点击明确的 `View Profile` 进入个人页，不让整块区域产生含糊行为。
- 手机端重排为五个纵向条目，每项含名字、缩略图和明确入口；不用 hover。

### Section 3 — Proof / 能力证明

- 一句简洁的 agency proof，不放大段宣言。
- 两个清晰入口：`Selected Work` 与 `Services`。
- 可展示 1–2 个数据点或合作类型，但不在此重复完整作品墙。
- 页尾保留联系/合作入口。

### Home 要移除的旧元素

- 排名徽章与 `MOST LOVED`；
- 五人同时挤在首屏；
- 轨道设备、五个节点、坐标与状态带；
- 多个自由落体/物理字块；
- 水晶 fallback 装饰；
- 与标题重叠的网格平面；
- 悬浮 manifesto；
- 17 组并行动画和无条件 RAF 循环。

## 5. Work 最终方案

方向：**1 个主推 + 8 个双列项目的编辑部作品墙**。

```text
SELECTED WORK
一句简短说明

┌──────────────────────────────────────────┐
│              主推项目 16:9                │
└──────────────────────────────────────────┘
OCTOPUS / AI FILM / 2026

┌────────────────────┐  ┌────────────────────┐
│      项目 16:9      │  │      项目 16:9      │
└────────────────────┘  └────────────────────┘
项目名 / 类型 / 年份       项目名 / 类型 / 年份
─────────────────────    ─────────────────────
```

- 第一支主推视频通栏；默认可先用 Octopus，最终可按业务优先级更换。
- 剩余 8 支组成四行双列。
- 所有视频容器严格 16:9、边缘对齐；不因源视频尺寸改变卡片比例。
- 桌面双列、手机单列；不再使用三列小卡片。
- 标题、项目编号、类型和年份移到视频画面外。
- 每个项目底部使用细分隔线与充足留白。
- 去掉画面上的巨大项目标题、常驻编号和常驻声音按钮。
- 当前 9 支视频继续使用本地 MP4，避免 YouTube 广告与外链不稳定。

## 6. 视频播放器与全屏

### 控件布局

```text
[播放] ───────────── 01:24 / 02:10  [声音] [全屏]
```

- 控件默认隐藏。
- 鼠标进入或键盘 focus 时，播放、进度、时间、声音和全屏一起淡入。
- 鼠标移出后约 160ms 淡出，进度条完全隐藏。
- 控件点击区域至少 44 × 44px，图标本身保持克制。
- 保留拖动进度、播放/暂停和声音开关。

### 全屏规则

- 右下角使用标准四角展开图标。
- 使用浏览器 Fullscreen API；`Esc` 退出。
- 桌面双击视频进入/退出全屏。
- 全屏背景近黑，视频 `object-fit: contain`，不裁切画面。
- iPhone/Safari 使用原生视频全屏兼容路径。
- 按钮提供 `aria-label`，状态变化同步更新。

### 触屏规则

- 第一次轻触显示控件；
- 用户再次点击具体控件执行操作；
- 不依赖 hover；
- 触摸设备不自动预览全部视频。

## 7. 动效总规则

### 保留三类

1. 页面内容揭示：420–520ms，行间 stagger 45–65ms；
2. Roster 肖像切换：220–300ms；
3. Home Hero 果冻玻璃：唯一的招牌连续交互。

### Work 动效

- 项目进入视区时轻微淡入上移；
- Hover 时底部分隔线展开；
- 视频封面不做持续缩放；
- 主推视频可在进入视区后静音预览 3–5 秒，但默认建议先关闭，待性能测试后决定。

### 无障碍与性能

- 支持 `prefers-reduced-motion`；
- 键盘可操作所有入口、Roster 和视频控制；
- 正文对比度至少 4.5:1，大字和 UI 至少 3:1；
- 页面不可见时暂停所有非必要渲染；
- WebGL 失败不影响导航、文字和 CTA；
- 桌面目标 60fps，中低端设备至少 45fps。

## 8. 暂不改动的范围

- 五位艺人的个人资料页结构；
- 已确认的艺人素材与人物身份信息；
- Work 的九支本地视频文件；
- Services 和 Contact 的业务字段；
- GTAI 基础品牌色；
- 后台/CMS、数据库和正式托管架构。

个人页只在本次公共 Header 调整时做兼容，不进行内容重构。

## 9. 推荐实施顺序

### Phase 1 — 静态结构

1. 做 Home 桌面 1440 × 900 和手机 390 × 844 线框；
2. 做 Work 桌面和手机线框；
3. 确认 Hero、Roster 和 Work 主推项目；
4. 无动效情况下先验证层级。

### Phase 2 — 代码整理

1. 备份现有可运行版本；
2. 拆出 Home、Work、Video Controls 模块；
3. 删除失效覆盖样式与旧动画生命周期；
4. 重建响应式 Header。

### Phase 3 — 页面实现

1. 实现 Home 三段式结构；
2. 实现五位艺人平等 Roster；
3. 实现 Work 的 1 + 8 编辑布局；
4. 实现视频全屏与控件显隐。

### Phase 4 — 动效

1. 加页面揭示与 Roster 切换；
2. 实现静态 3D 玻璃标志；
3. 加流体 UV 位移和轻视差；
4. 最后才评估 Work 的静音预览。

### Phase 5 — QA

- Chrome、Safari、Edge、Firefox；
- 桌面、平板、iPhone、Android；
- 鼠标、触屏、键盘；
- reduced-motion、WebGL 失败、低性能模式；
- 九支视频播放、拖动、静音、全屏与退出；
- 无横向溢出、无标题/肖像重叠、无首屏布局跳动。

## 10. 验收标准

- 用户 3 秒内能理解 GTAI 是 AI talent agency；
- Home 第一屏只有一个主信息和一个招牌视觉；
- 五位艺人没有排名，曝光面积与交互成本相等；
- 手机 Home 不再是桌面元素的压缩堆叠；
- Work 在桌面呈现 1 + 8 的清晰编辑节奏；
- 九支视频保持统一 16:9；
- 鼠标离开视频后所有控件与进度条隐藏；
- 每支视频都可键盘、触摸和鼠标操作并进入全屏；
- Hero 不包含贴纸掉落或额外物理散件；
- WebGL 关闭时网站仍完整可浏览；
- 首页可见范围内最多一个持续环境动效。
